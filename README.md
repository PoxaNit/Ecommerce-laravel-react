# Laravel Simple E-Commerce Application

A **Simple E-Commerce Application** built with Laravel. This project features a public storefront for browsing products, a functional shopping cart, and an administrative dashboard to manage the catalog.

## 🚀 Features

* **Product Catalog:** Dynamic display of items with titles, descriptions, pricing, and images on the homepage.
* **Shopping Cart:** Add and remove store items managed via session-based memory.
* **Admin Dashboard:** A restricted management portal allowing the store administrator to create, read, update, and delete (CRUD) products.
* **Native Authentication:** Secure login infrastructure protecting administrative dashboard routes from unauthenticated access.

---

## 🛠️ Prerequisites

Ensure you have the following installed on your machine:
* **PHP** (>= 8.2)
* **Composer**
* **MySQL** or **MariaDB**
